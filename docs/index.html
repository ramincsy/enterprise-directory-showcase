دفترچه سازمانی با عکس، موبایل، اطلاعیه و گزارش ادمین Photos, mobile & email, announcements, and admin reports — in one org phonebook

Colleagues open contact cards with a profile photo when uploaded (else a gendered demo avatar), plus mobile and email when privacy toggles allow; the holding publishes org announcements; operators run admin reports, activity audit, Excel import, backup & restore, theme, and 2FA. Frames are real product pages with sensitive rows anonymized.

Built for holding IT and multi-company orgs that need an on-prem Persian RTL PWA phonebook — not a cloud CRM contacts module. Privacy toggles (show_mobile / show_email) keep sensitive fields under admin control.

01 / 17 · Staff · Key capability

Staff directory — search, cards, mobile & email

Profile photo when uploaded Mobile action Email action Extension · search · filters

Search by name, department, or email; filter by company and department. Each card shows a profile photo when uploaded (otherwise a gendered demo avatar), the extension, and — when show_mobile / show_email allow — one-tap email and mobile actions. Dark mode and language live in the product chrome.

جستجو با نام، بخش یا ایمیل؛ فیلتر شرکت و بخش. روی کارت: عکس پروفایل در صورت آپلود (وگرنه آواتار دموی خانم/آقا)، داخلی، و با کنترل نمایش، اکشن ایمیل و موبایل. تم تیره و زبان در خود محصول است.

Card identities swapped to fictional demo people/companies before capture. Look for photo avatars plus email/mobile controls on the cards.

هویت روی کارت‌ها قبل از اسکرین با دادهٔ دمو عوض شده است. آواتار عکس و کنترل ایمیل/موبایل را روی کارت‌ها ببینید.

16 / 17 · Admin · Key capability

Add personnel photos — edit user & upload

JPEG / PNG / WebP Max 2 MB Shows on staff directory

From the people table, operators open Edit User to change bilingual names, company, gender, department, extension — and attach a profile photo (JPEG/PNG/WebP, max 2 MB). When uploaded, that photo becomes the avatar on staff directory cards; otherwise a gendered demo avatar is shown.

از جدول افراد، اپراتور «ویرایش کاربر» را باز می‌کند تا نام دوزبانه، شرکت، جنسیت، بخش، داخلی و عکس پروفایل را تنظیم کند. همان عکس روی کارت دفترچه دیده می‌شود تا همکاران افراد را بشناسند، نه فقط شماره داخلی.

17 / 17 · Admin · Key capability

Photo crop — drag, zoom, card preview

Drag to frame Zoom wheel / slider Circular card preview Server WebP

Before upload, a crop modal lets you drag to frame, zoom with the wheel or slider, and preview the circular card crop. Saved image is compressed to WebP on the server — so adding personnel photos is a guided, in-product flow.

قبل از آپلود، مودال برش امکان جابه‌جایی، زوم با اسکرول/اسلایدر و پیش‌نمایش دایره‌ای کارت را می‌دهد؛ تصویر روی سرور به WebP فشرده می‌شود — اضافه کردن عکس پرسنل یک جریان کامل داخل محصول است.
